# Flutter Social App

แอป Social Media รูปแบบ X-style ที่พัฒนาด้วย Flutter และ Firebase

## Features
- Register / Login
- Firebase Authentication
- User profile, username, avatar, bio
- Public feed
- Post / Like / Comment
- Audio support
- Delete post with confirmation
- Firestore persistence
- Firebase Storage

## Tech
Flutter, Dart, Firebase Authentication, Firestore, Firebase Storage
